# 设计稿原型说明

这是 **LUMEN 流明** 的高保真可交互设计稿，纯 HTML/CSS/JS 实现，用于确认视觉、布局和交互，不是最终 React 代码。

## 运行

```bash
# 在仓库根目录
cd design
python3 -m http.server 4173
# http://127.0.0.1:4173
```

也可以直接打开 `index.html`。字体、图片全部本地化，不依赖外部 CDN。

## 文件

```text
design/
├── index.html          页面结构（工作区/项目/创作台/Agent + API 弹窗）
├── styles.css          设计 token、布局、组件、响应式
├── app.js              层级导航、模式切换、上传、生成模拟、对比滑杆、视频时间线
├── assets/             本地字体 + 占位影像
└── screenshots/        1600×1000 @1.5x 截图（五模式、双视图、API、平板）
```

## 交互地图

| 操作 | 结果 |
| --- | --- |
| 左侧“工作区” | 进入工作区项目列表（顶层入口） |
| 项目卡 | 工作区 → 项目页 |
| 项目页“进入创作台” | 项目 → 创作台（五种生成模式） |
| 创作台“Agent 工作区” | 进入类 DSH 会话视图；属于创作台 |
| 顶栏面包屑 / 移动端顶栏按钮 | 按 工作区 → 项目 → 创作台 → Agent 工作区 层级前进/回退 |
| Agent 会话列表 / 新建会话 / 搜索 | 切换 active、创建空会话、过滤会话 |
| Agent 输入框 | Enter 发送；追加用户消息、Agent 打字状态与执行计划 |
| 工具卡 `details` | 展开/收起 inspect、分镜、生成结果 |
| “在创作台打开分镜表” | 切回图组视频分镜表 |
| 顶部五个模式标签 | 切换画布、提示词、参数与 CTA |
| `1` – `5` | 快捷切换模式（输入框内不触发） |
| 右侧比例按钮 | 修改画布比例标签与原型画幅 |
| 清晰度 / 时长 | 联动 tokens 预估与时长标签 |
| 清晰度 → 自定义 | 展开宽高、比例锁与快捷预设；图像 512–8192，视频 640–3840×360–2160 |
| 码率（视频） | 自动 / 8 / 16 / 自定义 Mbps；仅影响编码质量 |
| 动画模式（图生视频） | 实拍 / 2D / 3D / 定格；CTA 与画布标签联动 |
| 参考强度滑杆 | 百分比实时更新 |
| 添加参考图 / 首帧 / 批量 | 打开本地文件选择，生成缩略图 |
| 文生视频 / 图组视频的 `成片 | 分镜表` | 切换画布视图；分镜表为电影分镜表 |
| 智能优化 | 在提示词后追加镜头与质感描述 |
| 分镜表行内编辑 / 添加镜头 / 复制 / 删除 | 实时更新镜号、总时长与 tokens 预估 |
| AI 拆镜 / 导出 CSV | 重置示例分镜 / 下载 UTF-8 BOM 的 CSV |
| 生成按钮 / `⌘↵` | 模拟排队 → 渲染 → 完成，写入会话并累计 tokens |
| 文生视频播放键 | 播放 / 暂停，进度与时间码联动 |
| 图生图画布 | 拖动分割线对比参考图与结果 |
| 图组分镜列表 | 点击切换左侧预览；添加分镜显示提示 |
| 顶栏 API 状态 / 左侧 API 图标 | 打开 API 配置弹窗 |
| 窄屏下“参数” | 打开右侧参数抽屉；Esc 或点击遮罩关闭 |
| API 弹窗内测试连接 | 演示连接成功与延迟 |
| `Esc` | 关闭 API 弹窗 |

## 设计说明

- 导航层级：工作区 → 项目 → 创作台；Agent 工作区是创作台内部视图，不是顶层页面。
- 视觉方向：暗房 / 电影片场 / 琥珀光 / 胶片颗粒。
- 主色：`#E7B778` 琥珀；底色：`#07080A`；文本：`#F0ECE4`。
- 画布是视觉第一优先级；参数栏独立滚动，CTA 吸底。
- 所有图片经过统一暖/冷调色与叠加颗粒，保证占位素材的视觉一致性。
- 响应式：<1120px 隐藏参数栏，<800px 单栏；当前原型以桌面端验收为主。
